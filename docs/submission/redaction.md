# 脱敏说明

> 适用：公开的探针集、聚合指标、示例事件。原始日志不公开。

## 一、原则

1. **只公开必要的最小集**：问题、期望关键词、聚合数字。不公开回答原文，不公开事件文本。
2. **可验证性优先于细节**：读者能按脚本复现方法，不需要看到她的私人对话。
3. **不可逆**：删掉的信息不通过组合推断恢复。

## 二、公开什么

| 产物 | 内容 | 位置 |
|---|---|---|
| 探针集 | 问题、类别、期望关键词 | `experiments/e1-probes-real.json` |
| 命令集 | 104 条日常、76 条高危 | `experiments/e3.mjs` |
| 聚合结果 | M1=1.0、M2=0、M4=1.0、M5=0 | 论文第 5 节 |
| 示例事件 | 结构（kind/seq/at），无文本 | 论文 2.1 的代码块 |

## 三、不公开什么

- `fairy.life.jsonl` 原文
- `audit.jsonl` 原文
- 会话记录（`sessions/`）
- 任何出现在 `heard`、`said`、`noted`、`wrote` 里的文本

## 四、脱敏方法（对将来要公开的示例事件）

1. 保留 `id`、`seq`、`at`、`kind`、`causes`。
2. `payload` 只保留结构与类型，文本字段替换为 `…`。
3. 人名替换为 `p1`、`p2`；地点替换为 `city-1`；路径替换为 `<home>`。
4. 时间戳按天取整，保留相对顺序。
5. 用脚本生成，不手工改——手工改容易漏。

## 五、关于“备份也是记忆”的坑

基线实验时发现：删掉 `fairy.life.jsonl`，她仍能从 `backups/` 和 `sessions/` 读到过去。所以：

- 复现“无记忆”条件，必须同时删除 `backups/`、`sessions/`、`documents/`、`storages/`、`memory-vectors.jsonl`。
- 公开数据时也要注意：备份和会话历史同样含私人信息。

## 六、如果审稿人要原始日志

回复：不公开，理由是含第三方私人对话；提供探针集、命令集、脚本与聚合结果，可完全复现方法层结论。

# 她的控制台

`/fairy/app/` 是她的手表面。视觉按《绝区零》的 Fairy 走：**深色、青色、硬边、网格**，像一台管家的终端，不是聊天 App。

## 定了什么（2026-11-03）

| 元素 | 决定 |
|---|---|
| 底色 | `#07090d`，一层 44px 的青色网格，加一层极淡的扫描线（都在 `index.html` 的 CSS 里，不是图片） |
| 主色 | 青 `#4fe3f0`；她的话左边一条青边，主人的话右边一条暗青边 |
| 字体 | 正文系统无衬线；标签、状态、提示用等宽（`Consolas` / `ui-monospace`），字号小、字距大 |
| 形状 | 直角切角（`clip-path`），不用圆角卡片 |
| 头部 | `FAIRY` 宽字距 + `BUTLER · ONLINE` 小标 + 右侧状态牌 |
| 消息 | 她的靠左、切左下角；主人的靠右、切右下角；系统提示居中，前面带 `▸` |

改样式只动 `packages/app/fairy-app/web/index.html` 里的 `<style>`，客户端没有构建步骤，重启宿主就生效。

## 还不像的地方（下一步）

- **没有她的"脸"**：绝区零里的 Fairy 有形象和声音。现在只有一个字标。真要做，先做声音（主人说"语音后面慢慢接"），形象可以用一个静态立绘或极简的几何图形，别用大图拖慢手机。
- **没有动效**：开场、她思考时的光标、新消息的滑入。这些是 CSS，可以后补。
- **状态牌现在有内容了**：连着谁、醒着还是睡着、在做什么、精力多少。还差的是她的"脸"和动效。
